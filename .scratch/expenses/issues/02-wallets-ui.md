## Question

Design the wallet UI: a "Wydatki" tab in the navbar, a wallet list (showing name and transaction count?), create/rename/delete wallet flows, and how the user switches between wallets. Work with the human through the grilling skill.

## Answer

- Wallet list: name + transaction count (no sums yet).
- Create wallet: modal with a single name field.
- Switch wallet: select in the expenses page header.
- Delete wallet: confirm dialog with cascade warning (transactions will be deleted).
- Mobile: same responsive select, no separate mobile UI.
